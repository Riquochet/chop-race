# Chop Race

Live chart of The Chopping Block (a Sleeper guillotine league): every alive team's points through the week, on game time only, plus any alive team's players.

Page: https://riquochet.github.io/chop-race/

- `index.html` is generated from `chop_race.html` in Jack's Draft Day folder by `chop_gh.py page`. Edit the source there, not here.
- The data lives on the `data` branch (`live_doc.json`, one commit, force-pushed about every minute while games are live by the score recorder).
